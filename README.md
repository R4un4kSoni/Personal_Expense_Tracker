# Personal_Expense_Tracker

A lightweight, terminal-based expense tracking application written in Python. It allows you to log your daily expenses, view itemized summaries, and automatically saves your data persistently using a local JSON file.

## Features

* **Add Expenses:** Record new expenses with custom names and amounts.
* **Persistent Storage:** Automatically saves and loads your expense records using `data.json`.
* **Summary & Totals:** View all recorded expenses alongside a calculated grand total.
* **Input Validation:** Handles empty fields, negative numbers, and invalid text inputs gracefully.

## Prerequisites

Make sure you have Python installed on your system (Python 3.x recommended).

## How to Run

1. Clone or download this repository into a local folder.
2. Open your terminal or command prompt in that directory.
3. Run the application using the following command:

```bash
python main.py
